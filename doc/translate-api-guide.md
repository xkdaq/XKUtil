# 翻译服务 API 接入指南

## 百度翻译（已接入）

### 接入步骤

1. 访问 https://fanyi-api.baidu.com/ 注册账号
2. 进入"管理控制台" → "开发者信息"完成认证
3. 创建"通用文本翻译"应用，获得 `APP ID` 和 `密钥`
4. 在工具箱中：翻译 → 设置 → 百度翻译 tab 填入配置

### 注意事项

- 标准版：5万字符/月免费，QPS=1
- 高级版：100万字符/月免费，QPS=10（需个人认证）
- 尊享版：200+语种，需企业认证
- **标准版/高级版仅支持28种常见语言，不含印尼语和缅甸语**

---

## 有道翻译（已接入）

### 接入步骤

1. 访问 https://ai.youdao.com/ 注册账号
2. 进入"应用管理" → "创建应用"
3. 选择"文本翻译"服务，获得 `应用ID (AppKey)` 和 `应用密钥 (AppSecret)`
4. 在工具箱中：翻译 → 设置 → 有道翻译 tab 填入配置

### 注意事项

- 新用户赠送体验金（约50元），用完后按字符计费
- 支持100+语种，含印尼语、缅甸语
- 无固定免费月额度

---

## 阿里翻译（待接入）

### 接入步骤

1. 访问 https://www.aliyun.com/ 注册并完成实名认证
2. 进入阿里云控制台，搜索"机器翻译"，点击"立即开通"
3. 获取 AccessKey：
   - 控制台右上角头像 → "AccessKey 管理"
   - 建议创建 RAM 子用户，授予机器翻译权限后使用子用户 AccessKey
   - 获得 `AccessKey ID` 和 `AccessKey Secret`
4. 在工具箱中：翻译 → 设置 → 阿里翻译 tab 填入配置

### API 信息

- 接口地址：`https://mt.cn-hangzhou.aliyuncs.com/api/translate/web/general`
- 签名方式：HMAC-SHA1 (ROA 风格)
- 请求方式：POST，Content-Type: application/json

### 注意事项

- 通用版：100万字符/月免费
- 支持200+语种，含印尼语、缅甸语、越南语等
- 建议使用 RAM 子账号密钥，避免主账号泄露风险

---

## 腾讯翻译（待接入）

### 接入步骤

1. 访问 https://cloud.tencent.com/ 注册并完成实名认证
2. 进入腾讯云控制台，搜索"机器翻译"，点击开通
3. 获取 API 密钥：
   - 控制台 → "访问管理" → "API 密钥管理"
   - 建议创建子账号，授予机器翻译权限后使用子账号密钥
   - 获得 `SecretId` 和 `SecretKey`
4. 在工具箱中：翻译 → 设置 → 腾讯翻译 tab 填入配置

### API 信息

- 接口地址：`https://tmt.tencentcloudapi.com/`
- 签名方式：TC3-HMAC-SHA256
- 请求方式：POST，Content-Type: application/json
- Action: TextTranslate

### 注意事项

- 500万字符/月免费
- 支持70+语种，含印尼语、越南语等
- 建议使用子账号密钥
